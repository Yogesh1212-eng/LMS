**Project Details**

This is a full stack Learning Management System built using the MERN stack. It features a modern dark theme with blue and neon accents. Students can watch lectures, track their course progress, take quizzes after completing the syllabus, and download verifiable PDF certificates. Teachers have access to their own dashboard to create courses, upload video lectures, make quizzes, and monitor enrollments and revenue.

**Tech Stack**

1. Frontend: React, Vite, Tailwind CSS, Redux Toolkit, React Router, Framer Motion, Lucide Icons
2. Backend: Node.js, Express, MongoDB Atlas, Mongoose, JWT, Bcrypt, PDFKit, Multer
3. Hosting: Vercel for Frontend, Render for Backend

**Key Features**

1. Student Dashboard with course progress tracking and analytics
2. Video lecture player with automated completion status
3. Assessment quiz engine with pass and fail evaluation
4. Dynamic landscape PDF certificate generation with borders and verification stamp
5. Teacher dashboard for course creation and lecture uploads
6. MCQ quiz creator with custom pass percentage settings
7. Role based authentication for students and instructors
8. Course review and rating system
